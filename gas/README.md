# 結帳串接 Google 試算表 — 部署說明

整體流程：網站結帳 → `fetch` POST → Apps Script 網頁應用程式 → 驗證、以「菜單」重新計價 → 寫入試算表 → 回傳訂單編號。

## 1. 建立試算表與腳本
1. 建立一份新的 Google 試算表（例如「金穗鍋貼訂單」）。
2. 選單 **擴充功能 → Apps Script**，把 `gas/Code.gs` 的內容整份貼上（取代預設內容）並儲存。
3. 需要新訂單通知信的話，把 `CONFIG.NOTIFY_EMAIL` 改成你的信箱。
4. 在編輯器上方函式選單選 `setup`，按 **執行**，並依提示授權。完成後試算表會出現「訂單」「訂單明細」「菜單」三個工作表，狀態欄有下拉選單。

## 2. 部署成網頁應用程式
1. **部署 → 新增部署作業 → 類型選「網頁應用程式」**。
2. 執行身分：**我**；誰可以存取：**所有人**。
3. 按部署並授權，複製「網頁應用程式網址」（結尾 `/exec`）。
4. 用瀏覽器開該網址，看到 `{"ok":true,...}` 代表成功。

## 3. 接到網站
把網址貼進 `index.html` 的 `ORDER_API_URL`，合併上線即可。留空則是示範模式，不會寫入試算表。

## 日常操作
- 改價格、上下架：直接改「菜單」工作表（「供應中」取消勾選即暫停供應），網站不用改。
- 處理訂單：在「訂單」工作表的「狀態」欄用下拉選單更新。
- **修改 `Code.gs` 後要重新部署**：部署 → 管理部署作業 → 編輯 → 版本選「新版本」。網址不變。

## 注意
- 網站上顯示的價格來自 `index.html`，實際結帳金額來自「菜單」工作表。兩邊改價時要同步。
- 「所有人」可存取代表任何人都能呼叫這個網址，因此後端有欄位驗證、重新計價、蜜罐與頻率限制，但仍請勿在試算表放敏感資料。
